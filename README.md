# Ultimate Structures & Teleport Compass — Site Oficial

Site estático do addon para Minecraft Bedrock 1.26.51+ (sem build, sem dependências).

- `index.html` — página oficial (12 estruturas, bússola, progresso, instalação, FAQ)
- `styles.css`, `app.js` — tema e filtro interativo
- `assets/` — logo e ícone originais (pixel-art própria)
- `downloads/` — `.mcaddon` + `.mcpack` prontos para baixar

Publicado via GitHub Pages. Para atualizar: substitua os arquivos e faça push na `main`.
